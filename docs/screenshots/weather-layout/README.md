# Native weather review captures

Captured on a 1366×1024-point iPad simulator from the native Panel app using debug fixture data and a fixed animation phase. The current-condition description and icon were varied to exercise the existing atmospheric artwork; all other readings are synthetic fixture values and do not represent live weather. Night precipitation examples explicitly include “Night” in the condition to exercise the night branch.

The detail screenshots cover clear, partly cloudy, overcast, fog, rain, snow, clear, cloudy, overcast and foggy nights, night rain and snow, an empty forecast, and the unavailable-server state. The forecast fits on the panel without horizontal scrolling; compact devices retain vertical scrolling and wrap forecast hours.

# Native weather review captures

Captured on a 1366×1024-point iPad simulator from the native Panel app using debug fixture data and a fixed animation phase, except for the live shooting-star capture. The current-condition description and icon were varied to exercise the existing atmospheric artwork; all other readings are synthetic fixture values and do not represent live weather. Night precipitation examples explicitly include “Night” in the condition to exercise the night branch.

The detail screenshots cover clear, partly cloudy, overcast, fog, rain, snow, clear, cloudy, overcast and foggy nights, day and night thunderstorms, night rain and snow, an empty forecast, the unavailable-server state, and a shooting star. The forecast fits on the panel without horizontal scrolling; compact devices retain vertical scrolling and wrap forecast hours.

Visual research references: [Weatherwise](https://www.localwisdom.com/labs/weatherwise-mobile-app/), [Atmos](https://www.dianalwong.com/atmos), and [Weather App — Day, Evening & Night](https://dribbble.com/shots/25706661-Weather-App-Day-Evening-Night-UI-Design). These inform the use of condition-driven atmosphere, depth, and time-of-day palettes.

# App screenshots

Captured from the native macOS app on November 2, 2026 (Build 7 UI).

- `library.png`: library and player, 2080 × 1380.
- `player.png`: playback with sidebar hidden, 2080 × 1380.
- `recording.png`: live waveform, 2620 × 1380.
- `settings.png`: shortcut, native iCloud storage, and permission status, 2620 × 1380.
- `icon.png`: app icon from the asset catalog.

The window captures are unedited PNGs from macOS `screencapture -o -l`, preserving transparency at rounded corners. No white background is baked in.

The library and live scenes use an isolated Debug-only library generated by `Scripts/make-screenshot-fixtures.swift`, with synthetic PCM and meter samples. No microphone or system audio device is opened for these scenes. Settings shows the actual native iCloud setup and current permissions, with the sidebar hidden. No personal recordings appear in the published images. Screenshot settings are local Info.plist overrides; the fixture path and scenes are absent from release builds. The normal app configuration is restored after capture.

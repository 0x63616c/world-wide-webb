# Tendr 1.0.0 (11)

The medication amount now shows a directional arrow after “mg”: green up while the model is rising and muted down while it is falling. A flat estimate shows no arrow. The direction compares the current estimate with the same model one second earlier and works for live and selected chart times.

The main UI flow passed on iOS 26.2 Pro Max, including an assertion that the trend indicator exists. Reviewed actual simulator output: [Home](screenshots/build11-home.png). Release archive succeeded.

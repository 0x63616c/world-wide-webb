# Contributing

Read `CODEBASE_OVERVIEW.md` and `AGENTS.md` for repository conventions,
worktrees, checks, and required PR screenshots.

Use a task-named branch in a worktree. Source `.job.env` if present before
running checks, and run the relevant checks described in `AGENTS.md`.

PR titles use Conventional Commits, for example `feat(app): add thing`.
Include a summary, changes, testing, and the screenshot required by the PR template.
